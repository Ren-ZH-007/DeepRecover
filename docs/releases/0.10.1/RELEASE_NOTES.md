# DeepRecover v0.10.1 · 真实 U 盘测试后的改进

- 签名扫描跳过现存文件：NTFS / FAT32 / exFAT / APFS 分区上，完全位于文件系统仍在使用的区域（现存文件和系统元数据）中的签名命中不再入库，只计数显示，也不占用 10,000 条候选上限。可勾选“签名扫描也保留现存文件中的候选”恢复旧行为；无法读取分配信息时不跳过任何候选。
- 达到上限后继续：签名扫描因候选达到 10,000 条而停止时，可在“任务记录”中点“从断点继续”，核对来源后用新任务扫描剩余部分，原任务保持不变。
- 权限提示：macOS 无权读取磁盘设备时，直接给出临时授权命令（拔出设备后自动恢复）或制作镜像的建议；Windows 提示以管理员身份运行。
- 结果页默认隐藏系统自动生成又删除的文件（.Spotlight-V100、.fseventsd、.DS_Store、._ 附属文件等）；废纸篓中的文件照常显示。

## 范围与限制

签名扫描面向连续文件，不重组碎片，不证明候选曾被删除；跳过现存文件依据扫描时的分配状态。APFS 快照读取尚未在真实 Time Machine 外接盘上核对。其余限制与 v0.10.0 相同，见 docs/COMPUTER_RECOVERY.md 和 docs/APFS_DELETED_RECORDS.md。

提供 Windows x64、macOS Apple Silicon / Intel 便携预览包。macOS 为 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；真实手机、原始盘与桌面体验仍需实机验收。

发布工作流必须对本标签提交完成三平台测试、打包、程序启动与校验后才发布。实际结果以本版本 Actions 记录为准。
