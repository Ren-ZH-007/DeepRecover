# DeepRecover v0.8.0 · MP4/MOV 连续签名扫描

- 文件扫描和电脑磁盘/分区的签名模式新增 MP4/MOV，保留来源、源内绝对偏移、候选长度、范围 SHA-256 与检查依据。
- 联合核对容器盒、采样表和媒体范围，支持自包含、非分段的单 H.264 视频轨及可选 AAC 音轨；支持尾部 `moov`、多个 `mdat`、32/64 位盒和偏移。
- 候选接通视频筛选、静音预览、来源与目标双摘要导出及历史回读；源缺失时仍能查看历史，重新读取需核验来源。
- 截断、结构失败、边界未知、分段、加密、外部引用与资源限制分别显示原因；未通过验证的签名候选不能预览或导出。
- 视频单候选检查上限 64 MiB、`moov` 元数据 8 MiB；预览继续限制为 10 分钟、横竖屏 1080p、60 fps，并始终静音。
- 新增 30 项核心与界面测试，三平台构建门禁实际执行视频扫描、帧解码、精确范围导出和历史回读；测试样本均为合成数据。

源数据保持只读，处理在本地完成，不访问媒体外部引用。MP4/MOV 候选止于最后一个必需盒的末尾，不推断原文件的可选尾随数据，不重组碎片。容器与采样范围检查不等于逐帧解码或完整原文件重建，签名候选的删除状态未知；普通采集、复制和摘要一致均不表示已删除数据恢复成功。

提供 Windows x64、macOS Apple Silicon 与 Intel 便携预览包及 SHA256SUMS.txt。Windows 需保留整个解压目录，macOS 需保留完整应用；macOS 仍为 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证。M5 真实手机、备份、介质和安装体验验收仍待执行。
