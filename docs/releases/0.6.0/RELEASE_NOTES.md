# DeepRecover v0.6.0 · 本机诊断与 M5 验收准备

- 设置页新增本机环境检查，显示应用版本、系统与架构、Qt 显示环境、工作目录容量和 ADB 工具是否可定位。
- 诊断只读取环境与目录容量元数据，不启动 ADB、不枚举设备或扫描备份，也不打开源内容。
- 脱敏 JSON 只保存到当前工作目录的 `Reports`，使用独立新文件，不覆盖已有报告。保存前检查当前来源与工作目录隔离，拒绝同一原始盘或无法确认的映射。
- 报告采用固定字段，不包含用户路径、设备序列号、卷名或日志原文。手工验收项目始终为 `not_run`，不会因为环境检查通过而标为已验收。
- 增加 M5 实机操作清单与记录模板，并在原生打包验证中实际检查诊断窗口和报告保存流程。

本版本只推进实机验收的准备工具，真实手机、备份、磁盘/U 盘、Windows/macOS 桌面及安装体验仍需实际设备验证。现存文件采集、签名候选和摘要一致均不等于已删除数据恢复成功。APFS/HFS+ 仍仅提供连续 JPG/PNG 签名候选。macOS 应用仍未提供 Developer ID 签名或 Apple 公证，Windows 仍为便携包。
