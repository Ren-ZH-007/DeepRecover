# DeepRecover v0.10.0 · 断点续扫、更多格式与 APFS 删除记录候选

- 签名扫描支持手动从断点继续：停止、中断或读取失败后，从任务记录恢复；续扫前核对来源身份与近期候选摘要。删除记录解析仍需重新扫描。
- 新增 Office 文档连续签名扫描：docx / xlsx / pptx、doc / xls / ppt。
- 新增 WAV、带 ID3v2 标签的 MP3、M4A 音频连续签名扫描。
- 电脑恢复新增 APFS 删除记录候选：支持未加密、单卷、无快照的外接盘及原始镜像；检查布局、分配及可识别的覆盖情况，支持符合条件的多区段文件读取。
- 结果增加文件名和原始路径搜索、修改日期筛选、同任务重复内容标记及可选隐藏。
- 导出支持保留经安全清理的原文件名和目录，冲突自动编号；继续使用独占创建和 SHA-256 对照。
- 扫描显示速度和预计剩余时间；诊断报告新增脱敏磁盘映射及错误类型汇总。

## 范围与限制

签名扫描面向连续文件，不重组碎片，不证明候选曾被删除；Office 和音频的支持边界见对应说明。
APFS 不支持加密卷、多卷容器、快照、系统封存卷及 Fusion Drive；布局和分配检查通过不证明内容完整或恢复成功。详细边界见 docs/APFS_DELETED_RECORDS.md。
所有处理在本地完成，默认只读访问来源；导出摘要一致仅证明读取范围与输出字节一致。

提供 Windows x64、macOS Apple Silicon / Intel 便携预览包。macOS 为 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；真实手机、原始盘与桌面体验仍需实机验收。

发布工作流必须对本标签提交完成三平台测试、打包、程序启动与校验后才发布。实际结果以本版本 Actions 记录为准。
