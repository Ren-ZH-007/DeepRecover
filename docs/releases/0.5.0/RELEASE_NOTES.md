# DeepRecover v0.5.0 · 引导式来源选择与结果依据

- 按物理磁盘展示来源，区分系统盘、普通卷、APFS 容器、辅助卷与快照。仅明确识别的辅助项默认隐藏，可手动展开；未知来源继续保留。
- 启动时可图形化选择工作目录，选择前不创建工作数据库或日志。设置页和电脑页可在任务结束后切换目录，打开所选目录的历史，旧数据不自动迁移。
- 工作目录切换先检查已选原始盘的物理隔离和备份边界，拒绝管理文件链接、共享文件及未知数据库；同一目录由独占会话锁保护。
- 候选、内容检查、任务和导出状态中文化，保留原技术值提示。选中候选后可分别查看删除依据、内容检查和导出校验说明。
- 打包后验证增加工作目录选择与历史往返检查，原生 macOS 验证增加真实磁盘清单的分组元数据检查。

每次启动可选择已有或新工作目录；原有 `DEEPRECOVER_DATA_DIR` 配置继续支持。使用新版打开同一工作目录前，应先关闭旧版窗口。

扫描原始磁盘时，工作目录和导出目标仍须位于另一块物理磁盘。APFS/HFS+ 仍只有连续 JPG/PNG 签名候选，不解析删除记录。普通文件采集、布局/结构检查和摘要一致均不能直接表述为已删除数据恢复成功。真实硬盘/U 盘和手机备份仍待实机验收，macOS 应用未提供 Developer ID 签名或 Apple 公证。
