# DeepRecover v0.2.0 · 界面更新预览版

本版采用深蓝导航与浅色工作区，重新整理设备连接、本地索引、扫描、候选预览和导出校验的操作层级。

## 界面更新

- 品牌导航与统一线性图标，清楚区分主操作、辅助操作和停止操作。
- 总览改为三步入口卡片：连接与采集、定位与预览、校验与导出。
- 扫描页按来源选择、后台处理和能力边界分区；进度与状态集中展示。
- 结果页提供紧凑筛选、隔行表格、独立图片预览、分页与导出工具栏；来源详情可通过悬浮提示查看。
- 导出历史提供终态摘要、独立清单信息条和分页摘要对照，设置页分区展示本地路径与处理策略。

## 包含已验证的 QA 修复

合入 v0.1.0 发布后发现的六项缺陷修复：SQLite WAL/SHM 源副作用、跨来源备份目录写保护、已完成预览结果留存、Manifest 身份变化检测、索引路径越界，以及导出失败文案仍显示运行。

## Windows x64 下载与运行

下载 `DeepRecover-v0.2.0-windows-x64.zip`，解压后进入 **DeepRecover** 文件夹运行 **DeepRecover.exe**。必须保留并分发整个文件夹（包括 `_internal`），不能只复制 EXE。该 ZIP 为便携目录包，不是安装程序，不需要另装 Python。`SHA256SUMS.txt` 提供 ZIP 下载校验值。

Windows 包仅在原生 Windows runner 上通过测试、PyInstaller 编译和打包后 EXE 启动检查后发布。EXE 检查覆盖 7 页导航、SQLite v3、PNG/JPEG 插件、本地扫描→解码预览→2 项校验导出的真实流程，并确认源字节未变化。流水线保留测试和 EXE JSON 证据。Windows 的两项文件替换/符号链接权限场景明确跳过，不计为通过。

也可下载 GitHub 的 Source code 归档，使用 Python 3.12 与 requirements.txt 从源码运行。

## 能力与限制

仅在本机处理，原始来源保持只读；支持授权 Android 普通文件采集、未加密稳定 iPhone 备份索引、连续 JPG/PNG 候选扫描、图片预览及 SHA-256 对照导出。

**普通复制、候选定位和范围导出不等于已删除数据恢复成功。** 结构检查、可预览和摘要一致各有明确边界，不提供文件系统恢复、碎片重组、加密备份解密或取证写保护。

该版本为预发布：Windows 自动构建/离屏 EXE 验证不替代 Windows 10/11 交互体验、高 DPI、真实 USB 设备、真实备份或安装包验收。ADB 功能仍需另装官方 Android Platform Tools 并取得设备授权；视频预览尚未支持。
