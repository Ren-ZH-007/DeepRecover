# DeepRecover v0.9.0 · PDF 候选扫描与静态预览

- 文件扫描与电脑签名模式新增 PDF，核对传统交叉引用、对象范围、流长度及页树，保留来源、绝对偏移、长度、范围摘要和检查依据。
- PDF 候选可按文档筛选、分页/缩放预览、校验导出及历史回读；Android 采集副本、iPhone 备份和支持的电脑元数据候选沿用来源核验。
- 预览仅从已校验的内存字节渲染静态页面，不传入源路径或 URL、不创建文档副本；关闭、取消、改选与退出释放页面和文档数据。
- 首版支持传统交叉引用表、单一修订；对象/交叉引用流、增量修订、加密、脚本、表单、附件与外部引用保留为明确受限项，不执行或访问引用。
- 输入最多 16 MiB / 200 页，解析对象与解压量有上限；单页输出最多 400 万像素、约 8 秒，监测到驻留内存超过 512 MiB 会结束渲染进程。内存采样不等于统一硬配额。
- 三平台构建门禁实际执行 PDF 扫描、冻结程序的渲染工作进程、两页解码、缩放、释放、精确范围导出和历史回读，样本均为原创合成数据。

源只读、处理在本地完成。候选止于已校验 EOF 行，不推断原文件尾随数据或文件系统碎片；结构检查和预览不证明全部内容完整，也不证明文件曾被删除。普通文件采集、复制和摘要一致不描述为已删除数据恢复成功。

提供 Windows x64 与 macOS Apple Silicon / Intel 便携预览包。macOS 仍为 ad-hoc 签名，未进行 Developer ID 签名或公证。M5 实机按要求跳过，状态为未执行。
