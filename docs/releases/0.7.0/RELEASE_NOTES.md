# DeepRecover v0.7.0 · 本地视频预览

- 候选结果现在可预览自包含的 H.264 MP4/MOV：首帧、静音播放/暂停与进度拖动。
- 先校验来源，再从内存设备播放；不向播放器传入来源路径或 URL，不生成预览文件，不改写候选/导出状态。
- 分页、筛选、改选、换页、其他任务和退出会停止旧视频并释放缓冲与画面。修复加载期间立即关闭可能造成的后端释放阻塞。
- 首版限制为 64 MiB、10 分钟、1920×1080、最多 60 fps；仅无音轨或 AAC 音轨且始终静音。外部引用、播放列表、分段、加密、HEVC 及其他格式会明确拒绝。
- 原生编译门禁新增实际视频帧解码、静音、拖动和释放检查，使用自生成的合成视频，不是从用户数据提取的样本。

本轮不增加视频签名扫描、碎片重组或修复能力。播放准入和可播放不等于完整结构校验，也不等于已删除数据恢复成功。真实设备与备份、不同编码及安装体验的 M5 验收仍未完成；macOS 应用没有 Developer ID 签名或 Apple 公证。
