## 缺陷与修改闭环

| 编号 / 级别 | 修复前复现事实 | 修改 | 关闭依据 |
| --- | --- | --- | --- |
| BUG-QA-01 / 高 | SQLite mode=ro 仍在读取活 WAL 时改变 Manifest.db-shm；读取已 checkpoint 的 WAL 模式库也会创建 -wal/-shm。原版相关 3 项检查失败 | immutable 只读打开稳定库，拒绝非空 WAL/rollback journal，不替用户合并/删除源日志；前后不创建 sidecar | 活 WAL 原文件及 SHM 哈希不变；稳定 WAL 库/中文含空格与 # 路径不产生 sidecar；QA-03/09 与回归通过 |
| BUG-QA-02 / 高 | 导出只保护当前批次涉及的 iPhone 备份，Android 文件可导出到另一个已登记备份并显示 exported | 目标目录检查覆盖数据库中全部已登记 iOS 备份，不受 200 条任务列表上限或当前选择限制 | 原版[写入成功截图](qa/20261103/01-before-backup-write.png)与修复后[拒绝截图](qa/20261103/10-after-backup-write-blocked.png)；QA-08 哈希与未创建目录断言 |
| BUG-QA-03 / 中 | TaskManager 长期持有所有完成任务的 Future；12 次模拟预览后 12 个像素帧仍被引用 | 管理器只跟踪运行中任务，完成回调移除 Future；关闭时快照活任务再取消，避免锁住完成回调 | 12 次预览结果回归仅允许最后一个由测试变量持有的对象；活任务关闭取消不死锁 |
| BUG-QA-04 / 中 | Manifest 索引迭代期间文件身份/时间变化后仍可作为完成返回 | 结束时再次检查路径、文件身份、大小/时间及日志状态，变化则失败并保留“部分结果”语义 | 对原版修改 mtime 可复现未拒绝；修复后 BackupError 回归通过，不冒称完整索引 |
| BUG-QA-05 / 中 | Manifest.db 符号链接指向备份根目录外仍被读取 | 打开前解析并核验 Manifest 路径属于选定备份根目录 | 外跳链接回归通过；不改变外部 SQLite 源；Windows 链接权限限制另列 |
| BUG-QA-06 / 低 | 导出准备阶段已失败、pending 已清空，文案仍显示“正在导出… failed” | 最终文案按终态重建，并显示真实逐项计数；无批次时明确尚未生成文件 | [修复前中间态](qa/20261103/15-before-export-status-fix.png)、原版回归断言和[修复后](qa/20261103/10-after-backup-write-blocked.png)；失败不再显示正在 |

“高/中/低”为本轮缺陷影响判断。源读取可能仍更新操作系统访问时间，不提供取证写保护或不可变快照；没有把文件内容/目录清单未改变扩大为所有底层介质元数据完全不变。
