## M2 边界

- ADB shell 只用于 find/readlink/test，pull 只复制共享存储现存普通文件；不 root、不删除或写入设备。Android 列表最多 10,000 项，超限拒绝并提示缩小目录。设备工具支持与 USB 状态需实测。
- 采集源可能随时变化，路径与普通文件检查并非原子快照，副本摘要不证明源数据稳定。采集不提供取证级写保护；读取可能产生系统访问行为。
- 当前失败/取消的临时 pull 会清理；已提交的结果保留。Manifest 最多有不足 100 项未提交批次不保留；数据库故障/断电可能留下无索引副本。
- 结果元数据仅保存在本地 SQLite，不上传；来源路径和完整序列号属于本地敏感元数据，异常日志仅记录类型。
- 历史任务界面显示最近 200 项；回读不访问源设备，不能证明旧本地路径仍存在，不自动重采集。
