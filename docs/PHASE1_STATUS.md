## M2 边界

- ADB shell 只用于 find/readlink/test，pull 只复制共享存储现存普通文件；不 root、不删除或写入设备。Android 列表最多 10,000 项，超限拒绝并提示缩小目录。设备工具支持与 USB 状态需实测。
- 采集源可能随时变化，路径与普通文件检查并非原子快照，副本摘要不证明源数据稳定。采集不提供取证级写保护；读取可能产生系统访问行为。
- 当前失败/取消的临时 pull 会清理；已提交的结果保留。Manifest 最多有不足 100 项未提交批次不保留；数据库故障/断电可能留下无索引副本。
- 结果元数据仅保存在本地 SQLite，不上传；来源路径和完整序列号属于本地敏感元数据，异常日志仅记录类型。
- 历史任务界面显示最近 200 项；回读不访问源设备，不能证明旧本地路径仍存在，不自动重采集。

## M3 边界

- 扫描完整且结构检查通过仍是 candidate，不标记为恢复成功；不能区分现存与已删除数据。完整容器内嵌签名不单独报告。扫描阶段不提取，M4 用户确认后可单独导出来源校验通过的完整范围。
- PNG 解压仅检查 zlib 终结和扫描行布局，不反滤波；JPEG 不熵解码。基本结构通过不等于可解码、可预览或内容完整。
- 单候选检查上限 64 MiB、PNG 解压上限 256 MiB、10,000 候选上限；过大和不支持的 JPEG 模式标记 validation_limit/partial。错误和截断的长度仅表示检查范围，非确认边界。
- 源路径只以 rb 打开，末尾核对文件身份/大小/时间；源变化使任务失败，但不提供不可变快照或全文件哈希证明。
- 进度只在当前进程显示，历史保留任务状态与候选，不恢复进度或断点。

## M4 边界

- JPG/PNG 预览上限 32 MiB 输入、1,600 万像素、Qt 64 MiB 解码分配；不支持视频/其他图片格式。预览不生成文件、不修改候选状态，也不构成完整结构/内容验收。
- 新扫描保存源文件身份和范围摘要，新备份索引保存 blob 身份；缺少必要信息的历史记录只可回读，需重新扫描/索引后预览或导出。Android 旧副本已有摘要时仍可核验使用。
- 类型分类依据元数据，非真实格式识别。筛选跨页导出最多 10,000 项，不等同于自动导出所有任务。
- 输出使用新批次目录和独占创建文件，不使用原始名称拼接路径。源/目标 SHA-256 相同才标记独立导出记录 exported，原候选仍保留 candidate/原状态，不表示已删除数据恢复成功。
- 正常失败/取消清理当前输出并保留已校验项。数据库/权限/介质故障或断电可能遗留未完成文件或不完整清单；历史不自动重验目标，不支持续导。
- 来源路径、完整序列号及偏移等会保存在本地 SQLite 和导出 JSON，未上传；源文件身份检查不等于不可变快照，备份索引阶段未做全备份内容哈希。
