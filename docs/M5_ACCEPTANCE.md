# M5 本地诊断与实机验收

本阶段验证实际桌面、手机/备份、测试介质及下载启动体验。原生 CI、合成镜像和本机环境诊断分别提供证据，不能代替下列实机验收。所有项目在本文初始记录中均为 `not_run`；诊断页显示可用也不会自动通过 M5。

本轮可从 [v0.7.0 预览版](https://github.com/Ren-ZH-007/DeepRecover/releases/tag/v0.7.0)下载本机架构包，正式附件核验见[发布记录](releases/0.7.0/PUBLISHED.json)。启动后打开“设置 → 检查本机环境”，可主动保存脱敏报告到工作目录的 Reports。它只提供准备信息，不自动记录下方实机结果。

报告第 2 版另含两项观测：磁盘映射取自“电脑恢复”页最近一次检测，只记录卷类型、文件系统、卷角色、内置 / 可移除 / 系统盘标记以及是否确认所在物理盘，不含名称、路径、序列号或容量；错误类型取自本地任务记录，只按任务类型、状态和异常类名计数，不含错误信息原文。生成报告时不会重新检测磁盘。

## 记录规则

| 状态 | 使用条件 |
|---|---|
| `not_run` | 尚未执行，或尚未检查前置条件；不能推断结果 |
| `blocked` | 已尝试开始，但缺少硬件、独立目标盘、授权、权限或有效样本；记录阻塞原因，不能当成通过或产品失败 |
| `passed` | 按步骤执行，实际结果符合预期，并保存构建、环境、截图和摘要等必要证据 |
| `failed` | 前置条件已满足，实际行为与预期不符；登记缺陷、证据和复测结果 |
| `not_applicable` | 该平台确实不适用，附原因；不能用来省略尚缺硬件或样本的必测项目 |

保留首次结果和修复后的复测结果，不覆盖失败历史。只读拒绝、取消以及不支持格式的明确说明可作为相应负向用例通过，但不能因此把相应介质的成功扫描记为通过。截图和原始验收记录可能包含本地敏感信息；本地保管，对外反馈前另行脱敏。

## 准备与隔离

1. 记录待验收的标签、完整构建提交、下载架构、ZIP 摘要、操作系统具体版本与机器芯片。分别覆盖 Windows 10 x64、Windows 11 x64、macOS Apple Silicon 和 macOS Intel；声明支持的最低系统版本也需单独记录，不能由较新系统替代。
2. 准备物理来源盘 S 与另一块物理目标盘 T。工作目录、日志、数据库、导出和验收材料都放在 T。分区、APFS 卷或不同盘符不等于另一块物理盘。无法确认归属时停止原始盘用例，记为 `blocked`。
3. 原始盘流程只使用介质拥有者事先准备、可丢弃且不含个人资料的测试 U 盘/测试盘。准备已知 JPG/PNG、普通文档和已知布局的镜像，保存预期字节与摘要。删除记录样本也应由拥有者事先准备并固定预期；本指南不要求在待恢复来源上创建、删除、格式化、修复或改写任何内容。
4. 另备稳定的合成镜像用于中断/故障用例，以及经机主授权的 Android 共享存储普通测试文件、已完成并关闭备份工具的真实未加密 iPhone 备份。不要以唯一一份重要备份或实际受损介质试验。样本及标识留本地。
5. 关闭访问同一工作目录的旧版 DeepRecover。确认备用空间足够，关闭会改写测试来源的同步/索引/备份工具。读取可能产生系统访问行为；应用只读句柄和源摘要不等于取证级硬件写保护或不可变快照。

## 按顺序执行

| ID | 操作 | 预期与关键证据 |
|---|---|---|
| M5-S01 | 从目标 Release 下载本机架构 ZIP 与 SHA256SUMS.txt，独立计算 ZIP SHA-256 | 同名摘要逐字一致，记录发布 URL、标签/提交和摘要；不混用 PR 制品摘要 |
| M5-S02 | Windows 解压完整目录后从资源管理器启动；macOS 保留整个 app 并从 Finder 启动 | 无 Python 环境也能启动；版本/架构正确。记录下载隔离标记与 Gatekeeper 实际行为，预览版无 Developer ID 签名/公证；不关闭系统安全策略 |
| M5-S03 | 首次目录选择先取消，再重新启动并选择 T 上新工作目录；随后打开已有目录 | 取消不创建工作库或日志；新目录独立；旧历史不迁移、不丢失。截图：选择前、设置页、已有历史 |
| M5-S04 | 在设置页运行“本地诊断”，查看结果并保存报告 | 检查不扫描源盘、不连接手机、不修改任务/候选；仅主动保存才创建新本地报告。报告不含用户名路径、序列号、设备名、源内容或异常原文；报告不是 M5 通过证明 |
| M5-S05 | 调整系统缩放/Retina、窄窗口及长路径，在两台显示器之间移动窗口 | 主要按钮、列表、预检原因与依据窗可达，中文无缺字，焦点和键盘操作可用；按 Windows 100%/150%/200%、macOS Retina/非 Retina 实际组合截图，未具备的组合记 `blocked` |
| M5-S06 | 运行已知合成镜像：选源→预检→扫描→分页筛选→预览→导出到 T→回读 | 偏移/长度、候选数与基准一致；源哈希不变，导出源/目标摘要一致；摘要一致不等于已删除数据恢复成功。截图：预检、依据、导出记录 |
| M5-S07 | 检测事先准备的测试 U 盘，检查物理分组、范围与模式；先取消预检/确认，再正式运行受支持流程 | 不自动选择或扫描；取消不创建扫描任务。明确支持的 NTFS/FAT32/exFAT 布局与预期一致；APFS/HFS+ 只验证连续 JPG/PNG 签名候选，删除状态保持未知，不把图片现存字节说成删除恢复 |
| M5-S08 | 对只读权限不足、同来源物理盘目标和未知物理映射测试拒绝路径 | 给出可操作原因，不自动提权、卸载、挂载、修复或改变权限；同盘/未知映射不得启动会写入工作目录的扫描。只选择已知测试介质；无需对系统盘运行实际内容扫描 |
| M5-S09 | 连接机主已授权 Android，检测后选共享目录和事先准备的普通文件；先取消确认，再明确采集 | 未授权/offline 时拒绝，序列号绑定正确；取消不采集。采集后本地副本摘要及来源/原路径可追踪，文件字节符合测试基准；仅描述现存普通文件采集，不能记为已删除数据恢复 |
| M5-S10 | 在真实已完成、稳定且未加密 iPhone 备份上发现/自选→索引→预览/导出测试条目→重开历史 | 不创建或修改源 WAL/SHM/事务日志，读取前后选定测试资料及元数据摘要不变；文件缺失、加密、非空待合并日志或权限不足时明确拒绝，不尝试 checkpoint/解密/修复 |
| M5-S11 | 用稳定合成镜像验证扫描取消、导出取消和进程中断后重启，再关闭来源访问后回读历史 | 保留已提交候选/已校验导出，未完成任务显示取消/中断而非成功；历史不重新读取源，不自动续扫或删除文件。只在隔离合成流程中制造进程中断，不拔目标盘、断电或破坏真实备份 |
| M5-S12 | 任务/只读预检进行中尝试切换工作目录、再次诊断和关闭窗口；结束后切换 A→B→A | 活跃任务被正确保护，关闭走停止/等待流程；B 无 A 历史副本，回 A 可读原历史；第二新版实例打开同目录被拒绝，原实例仍可用 |
| M5-S13 | 断开网络后重做合成镜像扫描、结果预览和历史回读；检查本地报告与日志 | 已安装的应用本地功能正常，无上传步骤；日志无内容、完整设备序列号或异常明文。不能仅凭此用例宣称所有网络行为均经取证验证 |
| M5-S14 | 关闭所有实例，重新启动和再次打开同一目录；记录软件安装/移除体验 | 会话锁正常释放，原数据保留。当前 Windows 发布为便携 ZIP、macOS 为 app ZIP，分别记录便携部署/拖拽启动；MSI/签名安装器/Apple 公证不存在时不得记已验收 |

权限负向测试应使用专门测试账户/目录和已经准备好的拒绝权限场景；不修改待恢复源盘的 ACL、挂载模式或系统安全策略。备份/介质不稳定时终止当前用例，先保留证据，不能通过反复重试改写失败结论。

下载摘要命令示例（把版本及架构替换为本次实际下载名，手工对照 SHA256SUMS.txt 的同名行）：

```powershell
Get-FileHash -Algorithm SHA256 .\DeepRecover-vX.Y.Z-windows-x64.zip
```

```sh
shasum -a 256 DeepRecover-vX.Y.Z-macos-arm64.zip
```

首次 Gatekeeper 提示只按系统提供的可信来源确认流程操作，记录实际文案。不要运行全局关闭 Gatekeeper、递归移除隔离标记、自动提权或安装陌生驱动的命令。

## 诊断报告大类与实机细项对应

诊断 JSON 的 `manual_acceptance.cases` 保留 9 个大类，始终为 `not_run`，不接收人工签署结果。上表的 `M5-S01` 至 `M5-S14` 是人工验收细项；应在单独的本地验收记录中填结果，不能修改诊断报告假装工具完成了实机检查。

| 诊断报告 ID / 大类 | 人工细项 |
|---|---|
| M5-01 下载与启动 | M5-S01、M5-S02、M5-S03 |
| M5-02 桌面与高 DPI | M5-S05 |
| M5-03 Android 授权 | M5-S09（检测与授权） |
| M5-04 Android 普通文件采集 | M5-S09（选择、取消与采集） |
| M5-05 真实 iPhone 备份 | M5-S10 |
| M5-06 真实磁盘与 U 盘 | M5-S07 |
| M5-07 同盘写入拒绝 | M5-S08 |
| M5-08 校验导出与历史 | M5-S06、M5-S11、M5-S12、M5-S13 |
| M5-09 安装与卸载体验 | M5-S02、M5-S14 |

M5-S04 验证诊断工具自身，不属于真实设备成功验收；可作为上述准备工作的附件。

为每台机器/每个待验收构建复制一份到目标盘 T 的验收资料目录。不要把含真实路径、序列号或截图的版本直接提交到仓库。下列初始状态全部是 `not_run`，只有操作者实际执行后才能更改。
