# 来源选择与结果依据升级

0.5.0 开发功能，当前已发布版本为 v0.4.1。本轮落实磁盘选择与预检向导、工作目录图形化选择和结果展示改进。

## 工作目录

未设置 `DEEPRECOVER_DATA_DIR` 时，启动先选择工作目录；取消不会创建本地数据库或日志。可输入新目录，也可打开已有 DeepRecover 工作目录。设置页及电脑页提供切换入口：任务或只读预检进行中时不能切换，通过检查后打开独立工作区，不复制、迁移或删除原历史。

扫描原始盘时，工作目录及导出目标必须在另一块物理磁盘。当前选中的磁盘即使还没有检测分区，切换工作目录时也会检查物理隔离。不能把工作目录放在已登记的源备份、采集副本或应用包内。管理目录、数据库、日志及会话锁的重定向或共享文件会被拒绝；正在被其他新版实例使用的工作目录不能再次打开。

每次启动可重新选择目录；原环境变量配置继续直接打开指定目录。切换不会保存系统级偏好或自动生成启动脚本。打开同一目录前先关闭旧版窗口；旧版本不识别新会话锁。权限不足、目录占用或数据库版本不兼容时显示原因，可重新选择。

## 来源树与预检

来源按可确认的物理归属分组；跨盘容器保留全部物理成员。系统盘、文件系统和卷角色仅来自系统元数据，未知信息明确保留。只隐藏有可靠辅助卷/快照标记的项，不凭卷名猜测。检测和显示过滤都不会自动选择磁盘或开始扫描。

三步流程为：明确选择来源，检查工作目录隔离与分区，核对范围和扫描方式后确认。刷新、过滤、改选来源或失败重检会清除旧预检结果，不能继续使用旧范围启动任务。已选原始盘预检始终在后台只读执行，未通过时不创建扫描任务、不自动提权或卸载。

## 结果说明

候选状态和内容检查使用中文标签，技术值保留在提示中。选中一项点击“查看删除与检查依据”，分别阅读：

- 删除依据：区分文件系统删除记录、图片签名、备份索引与现存普通文件采集。
- 内容检查：区分布局检查、图片结构检查、截断、缺失、受限和未知结果。
- 导出校验：引导查看独立批次记录，不根据候选标记猜测是否已导出。有效且相同的来源/目标摘要才显示当次摘要校验通过；历史目标不会自动重验。

筛选、分页、更换结果或多选会关闭旧依据窗并清除旧选择。历史结果仍从本地记录读取，不重新访问来源。数据库及原始候选状态不因界面中文化或导出而改变；不展示虚构恢复率。

## 验证范围

自动化覆盖来源分组与过滤绑定、预检失败和取消、工作目录选择/切换/占用/只读边界，以及候选、内容、导出证据的区别。另有真实 Qt 与本地合成数据流程、原生 EXE/双架构 app 实际启动及工作区历史往返检查。原生磁盘检查仅查询系统元数据，不打开原始设备内容。

APFS/HFS+ 的签名模式、NTFS/FAT32/exFAT 的支持边界见[电脑恢复说明](COMPUTER_RECOVERY.md)。本轮没有增加文件系统删除解析能力，真实硬件、操作系统权限和安装体验仍属于 M5 验收。

364 项测试、三平台编译、工作目录往返与关键截图见[升级测试报告](GUIDED_RECOVERY_TEST_REPORT_20261104.md)。
