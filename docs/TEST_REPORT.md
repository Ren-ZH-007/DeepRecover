样本在临时目录自动构造，不含个人手机数据。界面预览为离屏渲染。
Android 测试使用注入的 subprocess runner 模拟设备和 pull，比较合成源文件哈希；未连接真实 USB 设备，不能据此声称已完成 Android 兼容性或取证只读验收。UI 测试模拟用户输入和确认，实际执行后台任务、采集服务、SQLite 和结果回读。
负面路径的 `task_failed type=ValueError/CandidateAccessError` 是预期日志；Qt offscreen 的 propagateSizeHints 提示不影响结果。没有通过跳过 Qt 测试获得通过结果。
本记录不是第一阶段整体测试报告：真实手机、真实备份、Windows、真实介质扫描/预览/导出和安装包尚未验收。100 项与额外工作流仅代表合成数据和自动化边界验证，不存在已删除数据恢复成功率或取证验收结论。目标路径替换和符号链接回归在 Windows 上可能因权限/打开文件语义明确跳过；本次 Linux 运行未跳过。现有 v0.1.0 发布未自动变更，修复须经合并/重新发布后才进入新下载版本。
