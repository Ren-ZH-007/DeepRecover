## 支持范围

| 来源/格式 | 本版行为 |
|---|---|
| MBR、扩展分区、GPT 镜像/磁盘 | 检查范围、重叠、循环，GPT 检查头/分区表 CRC；支持 GPT 512/4096 字节扇区识别 |
| NTFS | 读取已删除 MFT 记录；支持 resident DATA 的 USA 修复、nonresident 碎片运行列表和碎片 MFT；以 `$Bitmap` 检查数据簇分配状态 |
| FAT32 | 删除文件空内容或空闲单簇布局可进入校验流程；多簇删除后原链通常已消失，保留 `layout_unverified/partial`，不猜连续布局 |
| exFAT | 校验 boot/删除 entryset，读取完整名称；仅 `NoFatChain` 明确连续且分配位图为空闲的布局可校验导出 |
| APFS | 卷上有快照时，列出快照里还在、当前已删除的文件（快照版本，数据块须仍被占用）；另从已释放的文件树节点读取删除记录（名称、路径、区段），数据块须空闲、不被现存文件使用，且没有被其他已删除文件或元数据覆盖过，才可校验导出，见[说明](APFS_DELETED_RECORDS.md)。加密、多卷的容器拒绝解析 |
| HFS+ / 未知或损坏分区表 | 可选择整个源或可识别分区做连续 JPG/PNG/MP4/MOV/PDF/Office 文档/音频签名扫描；不解析其删除元数据 |
| BitLocker、FileVault、NTFS 压缩/加密/稀疏、属性扩展列表等 | 不解密、不猜测缺失布局；不支持的记录提示限制状态或拒绝元数据扫描 |

删除记录模式支持任意扩展名，分类来自名称元数据；图片预览仅 JPG/PNG，视频预览按自包含 H.264 MP4/MOV 的[支持范围](VIDEO_PREVIEW.md)执行，PDF 分页预览按[文档支持范围](PDF_PREVIEW.md)执行。签名模式检查连续 JPG/PNG 容器、受支持的 MP4/MOV 容器与采样范围、PDF 结构与对象范围，Office 文档的压缩包或复合文档结构（见[说明](OFFICE_SIGNATURE_SCAN.md)），以及 WAV / MP3 / M4A 音频结构（见[说明](AUDIO_SIGNATURE_SCAN.md)）。签名模式只能恢复连续存放的文件，碎片文件需靠 NTFS 删除记录的运行列表或 APFS 删除记录的区段读取。NTFS 暂以 `[$MFT record N]/文件名` 标识位置，不推测完整父目录；FAT32 短名称丢失的首字符显示 `_`，不伪造原字符。FAT32/exFAT 仅遍历现存目录，不追猜已删除目录的失效簇链。

## 使用步骤

0.5.0 启动时可图形化选择工作目录，也可继续使用 `DEEPRECOVER_DATA_DIR`。扫描原始盘前请选择另一块物理磁盘上的工作目录；设置页和电脑页可在任务结束后切换，旧历史不自动迁移。来源树及结果依据说明见[引导式操作说明](GUIDED_RECOVERY.md)。

0.6.0 设置页的“检查本机环境”可保存不含来源路径/设备标识的本地报告。报告不代替磁盘预检，也不自动通过实机验收；检查步骤见 [M5 清单](M5_ACCEPTANCE.md)。

1. 打开“电脑恢复”，选择镜像，或检测后明确选择本机磁盘/U 盘；检测不会自动开始扫描。
2. 等待只读分区预检，选择范围及“解析删除记录”或“签名候选”。不支持的文件系统会说明限制。
3. 确认来源后开始；可停止，已提交候选保留在本地索引。失败或取消不表示完整扫描。
4. 在结果页按类型/状态筛选、分页、预览。新增文件系统、删除依据和范围数量列；来源和碎片范围保存在本地记录中。
5. 选择导出目标，生成独立批次和 UUID 输出名称。按逻辑顺序读取范围、重新核对源摘要及目标 SHA-256，保存 JSON 清单和导出历史。

`deleted_record` 只表示读取到了删除元数据；`metadata_checked` 表示支持的布局/分配检查通过，不证明内容完整、从未覆盖或可用。`unknown` 表示签名扫描不能判断删除状态。部分、损坏、压缩、加密、分配已重用或缺少来源信息的候选不可导出为完整文件。导出状态 `exported` 只表示本次逻辑源范围与输出字节一致，不是无条件的恢复成功声明。

## 原始磁盘保护

原始设备始终使用只读句柄；不会自动提权、卸载、挂载、修复、修改分配表或回写源盘。Windows 使用只读 CreateFile/ReadFile 及查询 IOCTL，macOS 使用 O_RDONLY 与几何查询，读取按扇区对齐。Windows Storage Spaces、文件支持虚拟盘、RAID/网络存储池或未知总线无法证明底层物理隔离时，拒绝原始盘模式；可使用先行制作的稳定原始镜像。

**扫描原始盘之前，工作目录必须已在另一物理磁盘。** 同一磁盘上的另一个分区不算隔离。预检不建立数据库任务；通过检查后才建立扫描、预览或导出任务。历史回读后发起预览/导出也会重查当前工作目录；导出目标再次检查。Windows 跨盘卷、macOS APFS 容器映射无法可靠确认时拒绝，而非放行猜测。

例如从外置 E 盘保存工作数据后运行 Windows 程序：

```powershell
$env:DEEPRECOVER_DATA_DIR = 'E:\DeepRecover_Work'
& 'C:\Apps\DeepRecover\DeepRecover.exe'
```

macOS 例如：

```sh
DEEPRECOVER_DATA_DIR='/Volumes/OtherDisk/DeepRecover_Work' \
  /Applications/DeepRecover.app/Contents/MacOS/DeepRecover
```

上例路径需替换为实际另一块磁盘；不是要求将输出放到源盘。权限不足或设备不可用时会明确失败，不自动弹出提权流程。已有镜像文件不需要原始设备权限，也不需要挂载。

正在使用的系统盘可能被操作系统/其他程序持续写入，原始设备不是不可变快照；分配与删除状态基于扫描时观察，身份/范围摘要不能替代取证写保护。覆盖、SSD TRIM、加密、损坏或不足的元数据可能使内容不可读或失真。优先使用稳定镜像，不把未知/不完整记录标成已恢复。

## 限制和验证

删除记录单文件最多 8 GiB，最多 8,192 个物理范围；签名单候选检查最多 64 MiB，PNG 解压检查最多 256 MiB。每次最多 10,000 个候选、1,000,000 条元数据记录/目录项。达到限制明确失败或显示受限记录，不静默冒称完成。签名候选扫描可从断点手动继续（原始磁盘另须再次确认工作目录不在源盘上、分区未变，并复核最近已校验候选的摘要）；删除记录解析不支持断点续扫。原始 I/O 的取消需等待当前系统读取返回。图片预览沿用 32 MiB/1,600 万像素上限；视频上限为 64 MiB/10 分钟/横竖屏 1080p，见[视频说明](VIDEO_PREVIEW.md)。

自动化使用自行构造的 NTFS、FAT32、exFAT、APFS 和分区表镜像，验证源哈希不变、resident USA、碎片顺序、分配重用拒绝、越界/循环/取消、校验导出和历史回读。原始设备 API、磁盘枚举和物理盘隔离使用受控替身测试，不扫描云端真实磁盘；原生构建/镜像验证不能替代真实 USB、系统盘、权限和文件系统兼容性验收。

Windows/macOS 双架构的编译、270 项测试、电脑流程及关键截图见[测试报告](COMPUTER_TEST_REPORT_20261104.md)。
